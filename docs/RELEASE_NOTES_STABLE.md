**New since 1.19.100:**
- New look: the selected PC or game fills the top of the screen; about 0.8 MB smaller
- Stream Menu: Play/Pause on the remote, or hold Select + Start for 1 second
- App menu on the game tiles (CH+, Play/Pause, Select): resume, start, quit, hide
- *Rescan network* button to find PCs again
- Security: Smart Hub preview, pairing PIN, fixes from the Moonlight streaming library
- Fixed: a rare freeze, arrow keys scrolling settings, *Quit Running App* failing silently

**Which file?** Tizen 9 and newer: `Moonlight-ForceGM.wgt`. Tizen 5.5 to 8: `Moonlight.wgt`.

**Install** over the old app (settings and pairing normally stay), or next to the regular Moonlight app (pair your PC once).

**Moonlight S90C (v1.19.0-s90c.1)** won't announce 1.19.101: install it by hand.
