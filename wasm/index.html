    Navigation guide

    Remote Control (TV)
    Keyboard (Standard)
    Controller (Xbox layout: A = bottom button)
    • UP / UP ARROW / D-PAD UP / L-STICK UP — Navigate to the above view, previous item, category, option, or row, increase the IP address value, and increase the bitrate in 5 Mbps steps.
    • DOWN / DOWN ARROW / D-PAD DOWN / L-STICK DOWN — Navigate to the below view, next item, category, option, or row, decrease the IP address value, and decrease the bitrate in 5 Mbps steps.
    • LEFT / LEFT ARROW / D-PAD LEFT / L-STICK LEFT — Navigate to the previous item, and decrease the bitrate in 0.5 Mbps steps.
    • RIGHT / RIGHT ARROW / D-PAD RIGHT / L-STICK RIGHT — Navigate to the next item, and increase the bitrate in 0.5 Mbps steps.
    • OK / ENTER / SPACE / A — Navigate to the next view, select the current item, enable or disable settings, load the app or game list, and start the streaming session.
    • RETURN / ESC / B — Return to the previous view, close any active menu or dialog, cancel the operation, and exit the application with confirmation. During a stream, RETURN sends Esc to the PC.
    • CHANNEL UP / PLAY/PAUSE / F11 / SELECT — Open the menu of a PC or an app.
    • PLAY/PAUSE / SELECT + START (HOLD 1 S) — Open or close the Stream Menu during a stream.
    • START (HOLD 1 S) — Turn the mouse emulation on or off during a stream, if the Input Settings allow it (the Stream Menu always can): the left stick moves the pointer, the right stick scrolls, A or LB clicks left, B or RB clicks right, X or Y clicks the middle button.
    • RED / F1 / CTRL + ALT + SHIFT + Q / SELECT + START + LB + RB — Disconnect, while the app keeps running on the PC; cancels a stream that is starting.
    • YELLOW / F3 / CTRL + ALT + SHIFT + S / SELECT + LB + RB + X — Step the performance statistics overlay through Off, Compact and Full.
