    Navigation Guide

    Remote Control (TV)
    Keyboard (Standard)
    Gamepad (Xbox layout: A = bottom button)
    • UP / UP ARROW / D-PAD UP / L-STICK UP — Navigate to the above view, previous item, category, option, or row, increase the IP address value, increase the bitrate in 5 Mbps steps, and move the mouse cursor up in emulation.
    • DOWN / DOWN ARROW / D-PAD DOWN / L-STICK DOWN — Navigate to the below view, next item, category, option, or row, decrease the IP address value, decrease the bitrate in 5 Mbps steps, and move the mouse cursor down in emulation.
    • LEFT / LEFT ARROW / D-PAD LEFT / L-STICK LEFT — Navigate to the previous item, decrease the bitrate in 0.5 Mbps steps, and move the mouse cursor left in emulation.
    • RIGHT / RIGHT ARROW / D-PAD RIGHT / L-STICK RIGHT — Navigate to the next item, increase the bitrate in 0.5 Mbps steps, and move the mouse cursor right in emulation.
    • R-STICK UP / R-STICK DOWN — Scroll the mouse vertically in emulation.
    • R-STICK LEFT / R-STICK RIGHT — Scroll the mouse horizontally in emulation.
    • X / Y — Click the middle mouse button in emulation.
    • SELECT / ENTER / SPACE / A — Navigate to the next view, select the current item, enable or disable settings, load the app or game list, start the streaming session, and click the left mouse button in emulation.
    • RETURN / ESC / B — Return to the previous view, close any active menu or dialog, cancel the operation, exit the application with confirmation, and click the right mouse button in emulation.
    • LEFT BUMPER — Click the left mouse button in emulation.
    • RIGHT BUMPER — Click the right mouse button in emulation.
    • VOLUME UP / F9 / VOLUME DOWN / F10 / VOLUME MUTE / F8 — Adjust the TV volume: increase, decrease, or mute.
    • CHANNEL UP / PLAY/PAUSE / F11 / SELECT — Switch the mode of the IP address field, and open the menu of a host PC or an app.
    • CHANNEL DOWN / F12 / START — Set focus to the current item, and press & hold for 1 second to toggle mouse emulation for the gamepad.
    • PLAY/PAUSE / SELECT + START (HOLD 1 S) — Open or close the Stream Menu during the streaming session: resume, performance statistics, mouse emulation, keys for the PC, disconnect, and disconnect and quit the app.
    • RED / F1 / CTRL + ALT + SHIFT + Q / SELECT + START + LB + RB — Stop the streaming session.
    • YELLOW / F3 / CTRL + ALT + SHIFT + S / SELECT + LB + RB + X — Step the performance statistics overlay through Off, Compact and Full.
